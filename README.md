# Reinv — Real Estate Investment Platform (Monorepo)

Reinv is a full-stack real estate investment platform that leverages modern web technologies and blockchain concepts to enable secure, transparent, and user-friendly property investment workflows.

This repository is organized as a **monorepo**, containing the backend, frontend, wallet, smart contracts, and infrastructure configuration.

---

## 🚀 Features

- 🏢 Real estate investment platform
- 🔐 Blockchain-based ownership & transactions (smart contracts)
- 👛 Integrated crypto wallet interface
- 🌐 Modern web frontend
- ⚙️ Scalable backend API
- 🧱 Modular and clean project architecture
